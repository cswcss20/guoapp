# Hopeapp

多來源模組影視應用：內容由可安裝的站源模組提供，一個 app 睇晒唔同來源。

</div>

## 簡介

Hopeapp 係一個以「模組」為核心嘅影視播放 app。app 本身唔綁死任何單一站源，內容來自可以自由安裝同更新嘅模組；模組經內置的模組商店一鍵安裝，日後模組有更新，喺商店撳更新就得，唔使重裝 app。

## 主要功能

- **模組商店**：內置自家模組清單，一鍵安裝同更新各個站源模組。
- **Emby 模組**：登入你自己（或朋友）的 Emby 伺服器，瀏覽媒體庫、搜尋同串流播放。模組本身唔內置任何伺服器或帳號資料，伺服器網址同登入狀態只儲喺你部裝置入面。
- **播放器**：
  - 快退／快進掣，秒數可喺設定入面揀（5／10／15 秒）；
  - 字幕軌、音軌選擇（來源有多條軌嗰陣先會出現）；
  - 音畫同步微調，應付藍牙耳機延遲等聲畫唔同步情況；
  - 仲有倍速、清晰度切換、彈幕、定時停止等。
- **追劇同記錄**：追劇清單、觀看歷史、繼續觀看，全部只存喺本機，唔會上傳。

## 下載同安裝

去 [Releases](../../releases) 下載。現行 Release 係 **v1.0.0+119**。

- **Windows**：有安裝版同便攜版兩個選擇，二揀一就得。
  - 安裝版（`hopeapp-1.0.0.119-windows-x64-setup.exe`）：雙擊安裝，裝喺使用者目錄，唔使管理員權限。
  - 便攜版（`hopeapp-1.0.0.119-windows-x64.zip`）：解壓後直接執行入面嘅主程式，設定同記錄存喺程式隔籬嘅 `userdata` 資料夾，成個資料夾可以搬走。
- **iOS**（`hopeapp-1.0.0.119-ios-unsigned.ipa`）：未簽名 IPA，需要自行用側載工具簽名先裝到。
- **Android**：版本暫時停留喺 v2.0.4+116，去嗰個 Release 下載對應架構嘅 APK（一般手機用 arm64-v8a）直接安裝就得。

## 更新

app 未有配置更新伺服器，入面嘅「檢查更新」唔會自動下載新版。有新版嗰陣，去 Releases 下載新成品覆蓋安裝就得，設定同記錄會保留。
